What you need

WindowsWindows 10 or 11, 64-bit.
GraphicsAny Direct3D 11 graphics card.
The gameYour own copy of the original Xbox Forza Motorsport (2005, the retail release): either the game folder with default.xbe and media, or a disc image (.iso / .xiso).
Disk spaceAbout 4 GB: a copy of the game files (about 3 GB) plus FM X64, the compiled game code and caches.

Nothing else to install: FM X64 brings everything it needs, including the compiler that builds the game's converted code on your PC.

Steps

  1. Install

    Download the setup program (FMX64-version-Setup.exe) from the releases page and run it. It installs just for you, without admin rights, and adds FM X64 to the Start menu and the desktop.

    Prefer no installer? Download the .zip instead and unzip it into a folder you can write to, for example C:\Games\FM X64 (not under Program Files).

  2. Add game

    Open FM X64 and press Add game. Choose default.xbe in your game folder, or your disc image; you can also drop the folder or image on the window. If you put the game folder or image in the FM X64 folder first, the launcher finds it by itself.

    The launcher checks that it is the supported retail version, copies the game into its own folder, converts the game's code and compiles it. This happens once and takes a few minutes; progress is shown in the window.

  3. Play

    Pick your settings and press Play.

Everything stays in the FM X64 folder: game (your imported game), data (saves, logs, caches and the compiled code) and fm1_launcher.ini (settings). When a new version of FM X64 is installed, the launcher prepares the game again by itself. Uninstalling asks whether to keep your game and saves.

Settings worth knowing

Picture shape"Same as the window" follows your screen. 21:9, 32:9 and 48:9 widen the view.
Span all monitorsOne view across all your monitors. Use bezel correction if the picture doesn't line up across monitor frames.
Frame rate30 (original), 60, Custom (unlocked with a cap you choose) or Unlocked.
VSyncOn by default. Off allows tearing in borderless fullscreen for the lowest latency.
Internal resolutionHow many times the original 480 lines the game is drawn at.
UpscalingAMD FSR 1, or AMD FSR 4 for a cleaner 3D picture (FSR 3.1 on GPUs without FSR 4; needs Direct3D 12).
Frame generationExperimental, needs FSR 4 upscaling: doubles the pictures shown (30 becomes 60). Adds a little input delay; best with VSync on.
BenchmarkChoose a track and press Benchmark: the game's AI drives a lap and the frame rate is measured.

Controls

Xbox controllers work as on the console. Keyboard (game window in front):

DriveW accelerate, S brake, A / D steer
MenusArrow keys, Space A, Esc / Backspace B, X X, C Y, E black, Q white, Enter Start, Tab Back
WindowAlt+Enter fullscreen on / off

Keys, steering smoothing and dead zone can be changed in fm1_launcher.ini.

Problems

"Not the supported version": FM X64 supports the retail release of the game. Other builds are refused instead of being run wrongly.

"This folder can't be used": the launcher keeps the game and saves next to itself, so its folder must be one you can write to. Use the installer, or move the unzipped folder out of Program Files.

Something broke after an update: press Repair / re-import under the Play button and choose Rebuild the game code.

Updating: from 0.1.1 on, the launcher checks for new versions by itself and can install them for you (your game, saves and settings are kept). From 0.1.0, install the new version over your old folder.

Other problems: include fm1.log from the data folder when you report them.
